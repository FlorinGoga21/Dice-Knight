# Zombie artwork

The zombie follows the user's supplied reference: moss-green damaged head, exposed ivory skull patches, purple eyes, sparse dark hair, torn gray tunic, rope belt, ragged pants and bare feet.

The head and torso were generated with the built-in image generation tool, then separated and reduced with nearest-neighbor sampling for the existing SPUM animation rig. The original generated sheet is preserved as `ZombieGeneratedParts.png`. The production atlas is `Assets/Art/Enemies/Zombie/ZombieParts.png` (128 x 96, 64 pixels per unit, point filtering, no compression or mipmaps, six slices).

The arms and feet use the native `Human_1.png` SPUM shapes from the player, tinted moss green. The arms are zombie-specific copies in `Assets/Art/Enemies/Zombie/ZombieArms.png`: each remains exactly 6 x 7 pixels, with nine existing upper-arm pixels recolored as sleeve fabric. Their alpha, outlines and lower hand pixels are unchanged. There are no sleeve overlays. Their transforms match the skeleton exactly, with 32-pixel-per-unit sprite density and the original weapon grip. Native `Foot_3.png` SPUM pants are tinted charcoal. The four generated limb slices remain in the source atlas for reference but are no longer assigned to the prefab.

The torso's fixed shoulder flaps have been removed. `ZombieSleevelessParts.png` preserves that generated revision. Only the torso region of the production atlas was updated, using the original sampling bounds so the chest was not stretched after removing the shoulders. The sleeve pixels now move directly with each arm.

`Assets/Prefabs/Enemies/Zombie.prefab` remains a variant of the skeleton. It inherits combat, movement, damage effects, rewards, saving and the 19-weapon pool. Its existing animator supplies idle, movement, attack, hurt and death. No runtime art-generation code is required.
